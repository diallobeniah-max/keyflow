# KeyFlow Features

## Core

- Assign actions to keys and mouse buttons.
- Single, double, triple, long press, hold, combo, tap-then-hold, and sequence triggers.
- Configurable tap interval, hold duration, delay, and cooldown.
- Local-only storage.
- Global pause and safe mode.
- Conflict detection.
- Profiles and app rules.

## Actions

- Open app/file/folder/website
- Run command/PowerShell/batch
- Paste/type text
- Press shortcut
- Multi-action sequence
- Volume/media controls
- Screenshot
- Lock screen
- Open Windows settings
- Switch profile
- Show popup menu
- Show notification
- Clipboard/window actions
- Delay
